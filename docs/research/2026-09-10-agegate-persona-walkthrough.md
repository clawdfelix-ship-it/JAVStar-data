## 0. 現況（技術事實）

- Full-screen 固定遮罩（`fixed inset-0 z-[100]`，80% 深色 + backdrop-blur），中央卡片，**背景內容仍隱約可見**。
- 自我申報制：兩個按鈕「我已年滿 18 歲，進入網站」／「我未滿 18 歲，離開」，冇出生日期/身份驗證。
- localStorage 記**香港時區日期**，每日首次進站重彈；private mode 保守照彈。
- Denied：同一卡片切換成「抱歉，你未能進入」＋單一「離開網站」掣（去 google.com，要再 click 先跳，唔係即時 redirect）。
- 確認後 hero 內容**完全冇露骨素材**：粉紅可愛風、得女優數字/活動情報文字，似追星 app。
- 鎖 `body.overflow`，冇 X 關閉、冇 ESC、blocking（正確）。

## Persona A — 阿熙，28 歲香港男白領

| 欄位 | 值 |
|---|---|
| 到達 | IG story 見到女優香港活動 post → click |
| 處境 | 地鐵車廂／公司廁所，手機角度怕隔離望到 |
| 裝置 | iPhone，手機 |
| 恐懼 | 尷尬 > 一切。俾人見到 AV 相關字眼、俾網站嚇親、誤觸付費 |
| 風格 | Avoidant：要快、要事實、唔想答問題 |
| 目標 | 3 秒內入到去睇活動日期，唔留痕 |

### Fold A1 — 閘門彈出

**內心獨白**
> 「又係呢啲。『本網站含成人限定內容』——嘩好大隻字，隔離個阿叔睇到以為我睇緊 pornhub。其實我淨係想睇下邊個女優嚟香港開見面會……個粉紅底係咩呢，OK 似正經 app 啲。好啦好啦撳啦，唔好阻住我。」
> （一秒撳咗「進入」）

**分析師評估**

| 項 | 評估 |
|---|---|
| Emotional state | impatient（煩），唔係 anxious |
| Trust delta | **↑ 小**：粉紅品牌色、圓角卡片、繁體中文文案似香港正經產品，唔係西洋詐騙站 |
| LIFT | 主導 = **Distraction/Anxiety 輕微**：標題「成人限定內容」比實際內容（活動月曆）重；**Clarity ↑**：兩個按鈕零歧義 |
| Fogg | Motivation 高（IG 專登 click 入嚟）／ Ability 極高（一 click）／ Prompt 正住臉 → 必過，閘門對佢**零阻擋力但有少少尷尬成本** |
| Cialdini | Authority 弱（得個盾 icon，冇第三方 RTA/ASACP 標章）；Commitment 有（撳掣 = 自我聲明） |
| CTA reachable | ✅ 拇指位 |

**摩擦位**
1. **「成人限定內容」五隻大黑字 + 80% 遮罩**喺公共場合反而最引人注目——遮罩越黑越似「你喺度做緊見唔光嘅事」。對一個資訊站（唔係真色情站），語氣重量同實際內容唔對稱。
2. 冇「記住我」可選——佢知道自己每日都要再撳一次會煩（雖然合規上每日係 Felix 你嘅要求，保留）。
3. 通過時間 ≈ 1.5 秒，流失風險極低。

### Fold A2 — 入到 hero

**內心獨白**
> 「咦……7,598 個女優情報，又係粉紅色，冇相嘅？好乾淨喎。OK 快啲 search 個名。」

**分析師評估**
- Emotional：reassured。預期係「成人站」，實際見到似追星/月曆 app，**尷尬即時消解**。
- LIFT：Relevance 高（IG post 講活動，頁面就係活動情報）；Clarity 高（搜尋框最大）。
- Trust delta ↑：冇彈窗、冇付費牆、冇裸體。
- **唯一斷裂**：閘門把戲講到好重（成人限定！），入面甜到似少女月曆——有人會遲疑「係咪入錯網站」。建議閘門文案講明實際性質：「**成人女優活動情報網站，內容為活動/見面會資訊，不含影片**」，將預期對齊，仲可以降低公共場域尷尬。

## Persona B — 阿峰，35 歲香港男，第一次到訪

| 欄位 | 值 |
|---|---|
| 到達 | Google「XX 香港 見面會 2026」自然搜尋 |
| 處境 | 夜晚屋企，未聽過 J-STAR |
| 恐懼 | 釣魚/病毒、暗中收費、input 信用卡、假活動賣假飛 |
| 風格 | Anxious：每步要信任訊號 |
| 目標 | 確認呢個站係正經先好再撳 |

### Fold B1 — 閘門彈出

**內心獨白**
> 「『18+ AGE VERIFICATION』……OK 正常，成人嘢網站通常有。但係得個盾牌 logo，邊個做嘅？撳咗會唔會就係同意咗啲咩收費？佢寫『同意遵守當地法例』——即係同意啲咩？有冇 terms 睇？……算啦，冇叫我入信用卡，撳入去睇下，如果要俾錢我就走。」

**分析師評估**

| 項 | 評估 |
|---|---|
| Emotional state | cautious → 勉強通過 |
| Trust delta | **→ 中性**：閘門本身係正規訊號，但**冇任何一條可以 click 嘅條款/私隱/營運者連結**，焦慮冇被完全回應 |
| LIFT | Anxiety 未被處理：「同意遵守當地法例」係**空承諾**，冇 link 去 terms |
| Cialdini missing | Authority（冇 RTA/ASACP 之類業界標章）、Consensus（冇「已服務 X 用戶」——雖然 hero 有大數字，閘門後先見到） |
| Fogg | Ability 高，但 Motivation 未夠穩；**呢類人係唯一可能喺閘門流失嘅族群** |

**關鍵問題**
1. 「同意遵守當地法例」呢類法律句，**正常成年用戶（尤其 anxious）會想搵條款 link**——而家 dead end。閘門應該有細字連結去 `/terms`、`/privacy`（呢兩頁網站已存在）。
2. 冇講明**免費**。「進入網站」俾人嘅想像可以係付費牆。加「免費瀏覽 · 無需登記」可以直接拆焦慮。
3. 自我申報對佢唔係問題（佢唔關心未成年人嗰邊），但法律上「reasonable steps」角度，香港冇官方認證機制，self-declaration + 每日重確認 + denied 引導離開，已符合業界常見最低門檻；可再加分：footer/閘門放 **RTA website label** 或 ASACP「家长保護」連結（成人業界自我規範標章，免費）。

### Fold B2 — denied 狀態（模擬佢誤撳）

**內心獨白**
> 「喂我撳錯咗——『抱歉，你未能進入』？？我唔係未滿 18 啊！得個『離開網站』？返唔到轉頭㗎？」

**分析師評估**

| 項 | 評估 |
|---|---|
| 問題 | **冇補救路徑**：誤觸「未滿 18」之後冇「我撳錯咗，返回」選項，唯一出路係離開或者自己 reload（localStorage 冇記 denied，reload 其實會重彈，但用戶唔知） |
| 圖示語意矛盾 |  denied 頁頂仲係**盾牌+勾號**（✓ = 通過/安全），但語境係拒絕進入。應該用鎖頭/禁止 icon |
| 文案承諾唔兌現 | 「你即將被引導至其他網站」——但**冇即時跳轉**，要再撳「離開網站」先去 google。句子應該講「請按下方離開」或改為倒數自動跳轉 |
| 背景 | blur 咗但仍見到內容輪廓同底部 nav（截圖 02 可見）；法律上「已拒絕嘅人」理論上乜都唔應該見到。**建議 denied 狀態用不透底實色背景** |

## VERDICT

| 分數（1-10） | 分 | 理由 |
|---|---|---|
| Clarity（睇唔睇得明） | **8** | 兩個選擇零歧義；扣分在「成人限定內容」同實際內容（活動月曆）唔對稱、denied 引導句唔準 |
| Confidence（信唔信得住） | **6** | 賣相正經、冇付費陷阱外觀；但冇條款/私隱連結、冇業界標章、冇講免費，anxious 新客唔夠料 |
| Relevance | **8** | 18+ 門檻對成人女優內容合理；通過後內容同 IG/Google 到達意圖對齊 |

**整體**：合格偏穩嘅第一版（明顯贏過大部分雜牌成人站嘅黑底紅字 entry page），冇致命趕客缺陷。 persona A 1.5 秒通過、唔會流失；persona B 會猶豫但多數照入。

## 優先級建議

### 🟢 速贏（半個鐘內，高 CP 值）
1. **show 狀態加兩條細字 link**：使用條款 `/terms`、私隱政策 `/privacy`（頁面已存在）—— 處理 persona B 焦慮。
2. **加「免費瀏覽 · 無需登記」**一句喺按鈕上方或副文 —— 一句拆掉付費恐懼。
3. **文案對齊實際內容**：「收錄日本成人影視女優**活動、見面會資訊**」講清楚係情報站，降低公共場域尷尬（persona A）。
4. **denied 頁補「返回確認」文字掣**（reload 或 state reset）+ 將盾牌✓換成鎖頭/禁止 icon。
5. **denied 背景轉實色不透底**（`bg-white` 或深色 full-bleed 卡片），法律上乾淨啲。

### 🟡 重大改進
6. 「即將被引導至其他網站」改為 5 秒倒數自動跳 google.com（或叫用戶自己撳，二選一，唔好講咗又唔做）。
7. 加 **RTA / ASACP 自我規範標章**（細 icon + 外連，業界常見、免費、法律姿態分）。
8. 桌面版卡片太窄太多換行（截圖 04），`max-w-sm` 可以喺 md: 放到 `max-w-md`。

### 🔵 戰略（諗清楚先做）
9. 每日重彈係你嘅明確要求（合規姿態），但可以記「瀏覽器內 24h」+ 跨日先重彈（而家已係咁做），唔需要加長，維持。
10. 若將來有 IG/Google 付費投放，平台對成人 landing 審查會檢查年齡門檺——日後可考慮「出生年份」輕升級版（self-declare 嘅加強版，唔使真實 ID），而家未必要做。
